# 온톨로지 — 온톨컴퍼니 인사

> 개념 · 속성 · 관계 · 규칙으로 정리한 인사 지식. 각 개념이 `hr.db`의 어디에 있는지 함께 적는다.

## 1. 공통

- **기준 시점** = 2025-12-31. "현재", "지금"은 이 날.
- **기록 기간** = 2023-01-01 ~ 2025-12-31. 2022년 이전 결근 · 연차 기록 없음 (결근 없었던 것으로 봄).
- **회계연도** = 1월 1일 ~ 12월 31일.
- **날짜** = `'YYYY-MM-DD'` 문자열.
- **금액** = DB는 천 원 단위. 답은 따로 말이 없으면 원 단위.

### 하위 개념

- 부서
  - 본부: `level` = 1, `parent_cd` IS NULL
  - 실: `level` = 2
  - 팀: `level` = 3
  - 폐지 부서: `active` = 0, `closed_date` = 폐지일
- 사람
  - 재직자(X): `hire_date` ≤ X AND (`end_date` IS NULL OR `end_date` ≥ X)
  - 휴직자: `status` = 'L' (기준 시점에 육아휴직 · 산재 휴업 중) — 재직자의 하위 개념
  - 퇴사자: `end_date` IS NOT NULL, `status` = 'T'
  - 임원: `grade_cd` = 'E'
  - 직원(집계 대상, X): 재직자(X) 중 임원이 아닌 사람
  - 수습(X): X < 입사일 + 3개월 (같은 날짜, 없으면 말일)
- 소속
  - 주소속: `is_primary` = 1 — 한 시점에 하나
  - 겸직: `is_primary` = 0 — 0개 이상
- 부재
  - 결근 사유: 10 개인 사유, 20 병가
  - 출근 간주 사유: 30 육아휴직, 40 산재 휴업, 50 예비군 훈련
- 연차 사용 단위: D = 1일, H = 반차 0.5일, Q = 반반차 0.25일
- 달력일
  - 소정근로일: `is_workday` = 1 (월 ~ 금, 공휴일 구분 없음)
  - 범위: 2023-01-01 ~ 2025-12-31의 모든 날

## 4. 관계

| 관계 | 출발 | 도착 | 방법 |
|---|---|---|---|
| 상위 부서 | 부서 | 부서 | `parent_cd` → `dept_cd` |
| 하위 부서 (전이) | 부서 | 부서 | `parent_cd` 재귀 |
| 소속됨 | 사람 | 부서 | `emp_depts` (기간 있음) |
| 받음 (연봉) | 사람 | 연봉 | `salaries.emp_no` |
| 평가받음 | 사람 | 평가 | `evaluations.emp_no` |
| 부재함 | 사람 | 부재 | `absences.emp_no` |
| 발생함 | 사람 | 연차 발생 | `leave_grants.emp_no` |
| 사용함 | 사람 | 연차 사용 | `leave_usages.emp_no` |
| 이관됨 | 폐지 부서 | 부서 | 폐지일에 새 주소속 시작 |

- 폐지 부서의 이관: 이전 주소속 `to_date` = 폐지일 전날, 새 주소속 `from_date` = 폐지일.
- 임원은 본부에 주소속을 둔다.

## 5. 규칙

### 조직

- **O2 부서 인원(부서 D, 시점 X)** = D와 D의 모든 하위 부서에 X 시점 주소속을 둔 직원(X) 수.
- **O3 집계는 주소속만**: 부서 인원 · 부서별 집계에 겸직은 넣지 않는다.
- **O5 임원 제외**: 직원 집계 · 연봉 집계(평균 · 합계) · 성과급 대상에서 임원을 뺀다.

### 연봉

- **P2 시점 연봉(X)** = `effective_from` ≤ X 인 행 중 가장 늦은 행의 `amount_k`.
- **P2 연도 연봉(Y)** = Y-12-31의 시점 연봉. Y년 퇴사자는 퇴사일의 시점 연봉.
- **P5 연봉 집계(X)** (평균 연봉 · 연봉 합계 등): 대상 = 직원(X) 중 수습(X)이 아닌 사람. X 기본값 = 기준 시점.
- **P6 1일 통상임금** = floor(연봉(원) × 8 ÷ (12 × 209)). 연봉 기본값 = 연도 연봉.

### 성과급

- **P3 금액** = floor(평가 연도의 연도 연봉(원) × 비율).

| rating | S | A | B | C | D |
|---|---|---|---|---|---|
| 비율 | 20% | 10% | 5% | 0% | 0% |

- **P3 임원 제외**: 임원은 평가 기록이 있어도 성과급 없음.
- **P4 지급일** = 평가 연도 Y의 다음 해 3월 31일.
- **P4 수령 조건**: 지급일에 재직 중. 지급일 전 퇴사자는 못 받음.
- "Y년에 지급된 성과급" = (Y − 1)년 평가 기준.

### 근태

- **결근일** = 결근 사유(10, 20) 부재 기간 중 소정근로일.
- **R5 출근 간주**: 사유 30 · 40 · 50 기간은 출근으로 본다.
- **출근율(Y)** = (Y년 소정근로일 − Y년 결근일) ÷ Y년 소정근로일.

### 연차 발생 (`leave_grants`에 계산 결과가 있음)

- **R1** 근속 1년 미만: 입사일로부터 1개월 단위 구간에 결근이 없으면 구간 끝(입사일 + k개월)에 1일. 최대 11일.
- **R2** 첫 연간 연차: 1주년이 되는 달의 다음 달 1일에 14일. 출근율 따지지 않음.
- **R2-1** 이후 매년 1월 1일에 R3. R2 발생일이 1월 1일이면 그날은 R2만.
- **R3** 일수 = min(14 + (근속연수 − 1), 25). 근속연수 = 그해 1월 1일 기준 만 햇수.
- **R4** 직전 회계연도 출근율 < 80% → R3 대신 직전 회계연도 개근월(달력 월, 결근 없는 달) 수. 정확히 80%는 R3.

### 연차 사용 · 수당

- **R6 사용 일수**: D = 1, H = 0.5, Q = 0.25. 사용일 시점 잔여(그해 1월 1일 ~ 사용일 발생 − 같은 기간 사용)를 넘을 수 없음.
- **R7** 같은 회계연도 안에서 먼저 발생한 연차부터 차감.
- **R8 Y년 잔여** = Y년 발생 합 − Y년 사용 합. 이월 없음.
- **R8 수당 대상**: Y-12-31에 재직 중인 사람 (임원 포함). Y년 퇴사자 제외.
- **R9 수당** = floor(1일 통상임금 × 지급 일수)
  - 지급 일수 = floor(잔여 × 2) ÷ 2 (0.5일 단위 내림)
  - 1일 통상임금 = P6, Y년 연도 연봉 기준
  - 예: 연도 연봉 50,000(천 원), 잔여 2.75 → 2.5일 × 159,489 = 398,722원

## 6. 미정

- 지각 · 조퇴가 있는 달의 개근 여부 (지각 기록 없음)
- 연차 사용일을 출근율에서 출근으로 보는지
- 29 ~ 31일 입사자의 "1개월 뒤" 날짜 (해당 입사자 없음)

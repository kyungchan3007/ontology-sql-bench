# 업무 규칙 명세 — 온톨컴퍼니 인사 DB 조회

> 인사 DB(`hr.db`)로 질문에 답할 때 따라야 할 업무 규칙(BR)과 데이터 사전.

## 1. 개요

- DB: SQLite `hr.db`
- 기록 기간: 2023-01-01 ~ 2025-12-31
- 기준 시점: 2025-12-31 ("현재", "지금")
- 2022년 이전 결근 · 연차 기록 없음 → 결근 없었던 것으로 본다
- 직급 · 상태는 기준 시점 값만 있음 (이력 없음)

## 2. 업무 규칙

### 조직 · 인원

| ID | 규칙 |
|---|---|
| BR-01 | 부서는 본부(level 1) → 실(2) → 팀(3). 상위는 `parent_cd`, 본부는 NULL |
| BR-02 | 부서 인원 = 그 부서 + 모든 하위 부서의 주소속 인원 |
| BR-03 | 소속은 `emp_depts`. 주소속 `is_primary`=1(한 시점에 하나), 겸직 0 |
| BR-04 | 소속 기간 `from_date` ~ `to_date` 양 끝 포함, `to_date` NULL = 현재 |
| BR-05 | 부서 인원 · 부서별 집계는 주소속만 센다 |
| BR-06 | `employees.dept_old`는 갱신 안 되는 옛 값 → 소속 판단에 쓰지 않는다 |
| BR-07 | 재직자(X): `hire_date` ≤ X AND (`end_date` NULL OR `end_date` ≥ X) |
| BR-08 | `end_date` = 퇴사일(마지막 근무일). 휴직자(L)도 재직자 |
| BR-09 | 임원(`E`)은 직원 집계 · 연봉 집계 · 성과급 대상에서 뺀다 |
| BR-10 | 임원은 본부에 주소속을 둔다 |
| BR-11 | 폐지 부서: `active`=0, `closed_date`. 직원은 폐지일에 이관 (이전 `to_date` = 폐지일 전날) |

### 급여

| ID | 규칙 |
|---|---|
| BR-20 | DB 금액은 천 원 단위. 답은 따로 말이 없으면 원 단위 |
| BR-21 | 시점 연봉(X) = `effective_from` ≤ X 중 가장 늦은 행의 값 |
| BR-22 | 연도 연봉(Y) = Y-12-31 시점 연봉. Y년 퇴사자는 퇴사일 시점 연봉 |
| BR-23 | 연봉 집계(평균 · 합계) 대상(X) = 재직자 − 임원 − 수습, X 기본 = 기준 시점 |
| BR-24 | 수습(X): X < 입사일 + 3개월 (같은 날짜, 없으면 말일) |
| BR-25 | 1일 통상임금 = 연봉(원) ÷ 12 ÷ 209 × 8, 원 미만 버림. 기본은 연도 연봉 |

### 성과급

| ID | 규칙 |
|---|---|
| BR-30 | 성과급 = 평가 연도의 연도 연봉(원) × 등급 비율, 원 미만 버림 |
| BR-31 | 비율: S 20% · A 10% · B 5% · C 0% · D 0% |
| BR-32 | 임원은 평가 기록이 있어도 성과급 없음 |
| BR-33 | Y년 평가 → Y+1년 3월 31일 지급 |
| BR-34 | 지급일에 재직 중인 사람만 받음 |
| BR-35 | "Y년에 지급된 성과급" = Y−1년 평가 기준 |

### 근태

| ID | 규칙 |
|---|---|
| BR-40 | 소정근로일 = 월 ~ 금, 공휴일 구분 없음 (`workdays.is_workday`=1) |
| BR-45 | `workdays` 범위: 2023-01-01 ~ 2025-12-31 |
| BR-41 | 결근일 = 사유 10(개인) · 20(병가) 기간 중 소정근로일 |
| BR-42 | 사유 30(육아휴직) · 40(산재 휴업) · 50(예비군)은 출근 간주 |
| BR-43 | 부재 기간은 양 끝 포함, 주말이 끼어 있을 수 있음 |
| BR-44 | 출근율(Y) = (Y년 소정근로일 − 결근일) ÷ Y년 소정근로일 |

### 연차 발생 (결과는 `leave_grants`에 저장됨)

| ID | 규칙 |
|---|---|
| BR-50 | 1년 미만: 입사일 기준 1개월 구간에 결근 없으면 입사일+k개월에 1일, 최대 11일 |
| BR-51 | 첫 연간: 1주년 달의 다음 달 1일에 14일, 출근율 무관 |
| BR-52 | 이후 매년 1월 1일. 첫 연간 발생일이 1월 1일이면 그날은 14일만 |
| BR-53 | 연간 일수 = min(14 + (근속연수 − 1), 25), 근속은 그해 1월 1일 기준 만 햇수 |
| BR-54 | 직전 연도 출근율 < 80% → 직전 연도 개근월(달력 월) 수만큼. 80%는 BR-53 |

### 연차 사용 · 수당

| ID | 규칙 |
|---|---|
| BR-60 | 사용 단위 `unit_cd`: D 1일 · H 0.5일 · Q 0.25일 |
| BR-61 | 사용일 시점 잔여(그해 1/1 ~ 사용일 발생 − 사용)를 넘을 수 없음 |
| BR-62 | 같은 연도 안에서 먼저 발생한 연차부터 차감 |
| BR-63 | Y년 잔여 = Y년 발생 합 − Y년 사용 합, 이월 없음 |
| BR-64 | 수당 대상 = Y-12-31 재직자 (임원 포함), Y년 퇴사자 제외 |
| BR-65 | 지급 일수 = 잔여를 0.5일 단위로 내림 (2.75 → 2.5, 0.25 → 0) |
| BR-66 | 수당 = 1일 통상임금(Y년 연도 연봉) × 지급 일수, 원 미만 버림 |

- BR-66 예: 연도 연봉 50,000(천 원), 잔여 2.75 → 2.5일 × 159,489원 = 398,722원

## 3. 데이터 사전

| 테이블 | 컬럼 | 뜻 |
|---|---|---|
| departments | dept_cd · name | 부서 코드 · 이름 |
| | level | 1 본부 · 2 실 · 3 팀 |
| | parent_cd | 상위 부서 |
| | active · closed_date | 1 운영 · 0 폐지, 폐지일 |
| employees | emp_no · name | 사번 · 이름 |
| | hire_date · end_date | 입사일 · 퇴사일 |
| | status | A 재직 · L 휴직(육아 · 산재) · T 퇴사 |
| | grade_cd | G1 사원 ~ G6 부장, E 임원 |
| | dept_old | 쓰지 않음 (BR-06) |
| emp_depts | is_primary | 1 주소속 · 0 겸직 |
| | from_date · to_date | 소속 기간 |
| salaries | effective_from · amount_k | 적용 시작일 · 연봉(천 원) |
| evaluations | year · rating | 평가 연도 · S~D |
| absences | from_date · to_date | 부재 기간 |
| | reason_cd | 10 개인 · 20 병가 · 30 육아 · 40 산재 · 50 예비군 |
| leave_grants | grant_date · days | 발생일 · 일수 |
| leave_usages | use_date · unit_cd | 사용일 · D/H/Q |
| workdays | date · is_workday | 날짜 · 1 소정근로일 |

| grade_cd | G1 | G2 | G3 | G4 | G5 | G6 | E |
|---|---|---|---|---|---|---|---|
| 직급 | 사원 | 주임 | 대리 | 과장 | 차장 | 부장 | 임원 |

## 4. 미정

- 지각 · 조퇴가 있는 달의 개근 여부
- 연차 사용일을 출근율에서 출근으로 보는지
- 29 ~ 31일 입사자의 "1개월 뒤" 날짜

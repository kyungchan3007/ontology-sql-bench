# 용어집 — 온톨컴퍼니 인사 DB

> 용어 · 코드 · 컬럼의 뜻만 담는다. 계산 규칙과 집계 기준은 담지 않는다.

## 용어

| 용어 | 뜻 |
|---|---|
| 기준 시점 | 2025-12-31. "현재", "지금"은 이 날 |
| 기록 기간 | 2023-01-01 ~ 2025-12-31 |
| 회계연도 | 1월 1일 ~ 12월 31일 |
| 재직자 (시점 X) | 입사일 ≤ X, 퇴사일 없음 또는 퇴사일 ≥ X |
| 휴직자 | `status` = 'L' (육아휴직 · 산재 휴업 중). 재직자에 포함 |
| 퇴사일 | `end_date`. 마지막 근무일 |
| 임원 | 직급 `E` |
| 본부 · 실 · 팀 | 부서 단계. `level` 1 · 2 · 3 |
| 상위 부서 | `parent_cd`. 본부는 NULL |
| 폐지 부서 | `active` = 0, 폐지일 `closed_date` |
| 주소속 | `emp_depts.is_primary` = 1. 한 시점에 하나 |
| 겸직 | `emp_depts.is_primary` = 0 |
| 소속 기간 | `from_date` ~ `to_date` (양 끝 포함), `to_date` NULL = 현재 |
| 옛 부서 | `employees.dept_old`. 옛 시스템 값, 갱신 안 됨 |
| 수습 | 시점 X에 입사 후 3개월이 지나지 않은 직원 |
| 시점 연봉 | `effective_from` ≤ X 인 연봉 중 가장 최근 값 |
| 연도 연봉 | 그해 12월 31일(그해 퇴사자는 퇴사일)의 시점 연봉 |
| 천 원 단위 | DB 금액 단위. `amount_k` 50000 = 5천만 원 |
| 소정근로일 | 월 ~ 금. 공휴일 구분 없음. `workdays.is_workday` = 1 |
| 결근 | 소정근로일 중 출근 간주가 아닌 결근 · 휴직일 |
| 출근 간주 | 육아휴직 · 산재 휴업 · 예비군 훈련 |
| 출근율 | (소정근로일 − 결근일) ÷ 소정근로일, 직전 회계연도 |
| 근속연수 | 입사일부터 만으로 채운 햇수 |
| 연차 발생 | `leave_grants`. 이미 계산된 결과 |
| 연차 사용 | `leave_usages` |
| 반차 · 반반차 | 0.5일 · 0.25일 |
| 1일 통상임금 | 연봉(원) ÷ 12 ÷ 209 × 8, 원 미만 버림 |
| 성과급 | 평가 등급에 따른 연봉 비율 지급액 |
| 연차 수당 | 연말 미사용 연차에 대한 지급액 |

## 코드

| 컬럼 | 값 | 뜻 |
|---|---|---|
| `employees.status` | A | 재직 |
| | L | 휴직 |
| | T | 퇴사 |
| `employees.grade_cd` | G1 | 사원 |
| | G2 | 주임 |
| | G3 | 대리 |
| | G4 | 과장 |
| | G5 | 차장 |
| | G6 | 부장 |
| | E | 임원 |
| `absences.reason_cd` | 10 | 개인 사유 |
| | 20 | 병가 |
| | 30 | 육아휴직 |
| | 40 | 산재 휴업 |
| | 50 | 예비군 훈련 |
| `leave_usages.unit_cd` | D | 1일 |
| | H | 반차 |
| | Q | 반반차 |
| `evaluations.rating` | S · A · B · C · D | 평가 등급 |

## 테이블

| 테이블 | 한 행 |
|---|---|
| `departments` | 부서 |
| `employees` | 직원 (직급 · 상태는 기준 시점 값) |
| `emp_depts` | 소속 이력 |
| `salaries` | 연봉 변경 (천 원) |
| `evaluations` | 연도 평가 |
| `absences` | 결근 · 휴직 기간 (주말 포함 가능) |
| `leave_grants` | 연차 발생 |
| `leave_usages` | 연차 사용 |
| `workdays` | 달력 하루 (2023 ~ 2025) |

# 과제: 온톨컴퍼니 인사 DB 질문에 답하기

너는 온톨컴퍼니 인사팀의 데이터 조회 담당이다. 질문 하나를 받으면 `hr.db`를 조회해 답한다.

## 조회 방법

- DB: 이 폴더의 `hr.db` (SQLite, 읽기 전용)
- 명령은 한 번에 하나씩, 아래 형태로만 실행한다. `&&` · `;` · `|` · `cd`로 여러 명령을 잇지 않는다.

```bash
sqlite3 -readonly hr.db "SELECT ..."
```

- 이 폴더에 함께 있는 문서를 참고한다.

## 답하는 방법

- 답은 이 폴더의 `answer.json`에 저장한다.

```json
{ "answer": 123, "sql": "답을 구한 마지막 SQL" }
```

- `answer` 형식
  - 숫자 하나를 묻는 질문: 숫자 (예: `123`, `2416.25`). 따옴표 · 쉼표 · 단위 없이
  - 목록을 묻는 질문: 질문에 적힌 모양의 배열 (예: `[["영업1팀", 45], ["인사팀", 24]]`)
- 사용자에게 되묻지 않는다. 애매하면 문서를 근거로 가장 타당한 해석을 골라 답한다.
